## The joke

> HR approved my leave request in 3 seconds, which is the fastest anything has ever moved in this office, including the fire drill.

## How it works

`main.ts` is a small deterministic TypeScript program (no network, no
randomness). Run it with the harness output directory set and it writes
exactly that one line to `entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

The output is 129 characters of UTF-8 text — inside the competition's
1–200 character gate — and byte-identical on every run.
